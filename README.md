1. Objetivo do projeto 
O objetivo principal do projeto foi criar um sistema prático, funcional, 
organizado, que controle todo o fluxo de uma rotina de atendimento 
hospitalar.

3. O que o sistema faz 
Possibilita que os funcionários, a partir de seus respectivos cargos, 
acessem as áreas que lhes competem e gerenciem seus atendimentos 
controlando entradas, tratamentos, permanências e altas dos pacientes. 

4. Utilidade desse sistema 
O sistema traz utilidade real e prática para um hospital. Aqui estão os 
principais pontos de valor: 

● Otmização da gestão e assistência. 

● Centralização das informações 

● Automatização de processos administrativos e assistenciais 

● Redução de erros e melhoria da qualidade do atendimento ao 
paciente.   

5. Linguagens de programação e marcação utilizadas 

• JavaScript 

• HTML 

• CSS 

6. Segurança e Modernização 
A construção do sistema interno de funcionários para o controle de 
pacientes também exigiu atenção especial aos aspectos de segurança e 
modernização, considerando que o projeto envolve dados sensíveis e 
informações internas da organização.
